#  Лабораторная работа №5

##  Описание проекта

Данное приложение представляет собой веб-систему для учета финансовых транзакций.  
Пользователь может добавлять доходы и расходы, просматривать список операций, удалять записи и видеть общий баланс.

Приложение реализовано на чистом JavaScript и работает на стороне клиента.

---

##  Архитектура проекта

Проект состоит из следующих модулей:

- `index.html` — интерфейс приложения

#  DOM и JavaScript

## 1. Каким образом можно получить доступ к элементу на веб-странице с помощью JavaScript?
Доступ к элементам DOM осуществляется через методы поиска:
- `getElementById()` — по ID  
- `querySelector()` — по CSS-селектору  
- `querySelectorAll()` — все совпадения  

---

## 2. Что такое делегирование событий и как оно используется?
Делегирование событий — это способ обработки событий через родительский элемент, используя механизм всплытия событий. Это позволяет не назначать обработчики каждому элементу отдельно и удобно работать с динамическими элементами.

---

## 3. Как можно изменить содержимое элемента DOM?
Содержимое элемента можно изменить после его выбора:
- `textContent` — изменение текста  
- `innerHTML` — изменение HTML  
- `value` — для полей ввода  

---

## 4. Как добавить новый элемент в DOM дерево?
Сначала создается элемент через `createElement()`, затем задается его содержимое и он добавляется в DOM с помощью `appendChild()` или других методов вставки.
